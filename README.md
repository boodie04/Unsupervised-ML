# Unsupervised-ML
A collection of unsupervised machine learning models including clustering algorithms like DBSCAN, K-Means, and Hierarchical Clustering. This repository focuses on implementation, visualization, and performance analysis of these models on both spherical and non-spherical datasets.

# Unsupervised Machine Learning Models

This repository contains implementations of various **unsupervised machine learning** algorithms, focusing primarily on clustering and pattern discovery in unlabeled datasets. These methods are particularly useful when the goal is to group similar data points, detect anomalies, or reduce the complexity of data for visualization and interpretation.

---

## 🧠 What’s Inside

This project currently includes:

- 📌 **DBSCAN (Density-Based Clustering)**
- 📌 **Enhanced DBSCAN** (with improvements for non-spherical data)
- 🛠️ Utility functions for distance calculations and neighborhood analysis
- 📊 Visualizations for clusters, borders, and noise points
- 🧪 Sample datasets (both synthetic and real-world)

Future updates may include:
- K-Means clustering  
- Hierarchical clustering  
- Dimensionality reduction (e.g., PCA, t-SNE)
